# v1.4.0

LAS Point Cloud Viewer `v1.4.0` 新增 3D Gaussian Splatting PLY 模型加载与 GPU 渲染，并完善大文件异步加载和软件内各数据入口。

## 下载包

- `LASPointCloudViewer-v1.4.0-windows-x64.zip`
  - 面向 Windows x64 桌面环境
  - 包含 Qt、OpenSceneGraph、QtitanRibbon、LASlib/LASzip、PROJ 等运行依赖

## 主要更新

- 支持加载 3D Gaussian Splatting binary little-endian PLY 模型
- 使用 OpenGL 4.3 SSBO 和实例化四边形进行 GPU Gaussian 渲染
- 支持 SH0 颜色、透明度、缩放、旋转及三维协方差
- 大型 PLY 文件在工作线程解析，并使用多核并行转换和排序
- 支持拖放、Ribbon、项目树、通用打开和工程恢复等数据入口
- 完善 Gaussian 模型的视图适配、项目树状态和中文翻译
- 修复异步加载失败、清空场景及模型替换过程中的状态同步问题
- 新增可配置的内嵌网页面板

## 使用方式

1. 下载 `LASPointCloudViewer-v1.4.0-windows-x64.zip`
2. 解压到任意本地目录
3. 运行 `LASPointCloudViewer.exe`
4. 从软件的数据入口加载 `.las`、`.laz` 或受支持的 Gaussian `.ply` 文件

## Gaussian PLY 说明

- 当前支持 binary little-endian、float32 属性的 PLY
- 必需属性为 `x/y/z`、`f_dc_0..2`、`opacity`、`scale_0..2`、`rot_0..3`
- 当前渲染 SH0 颜色，不支持 SH1-SH3
- Gaussian 模型与 LAS/LAZ 点云当前不支持同屏显示
- GPU 渲染需要支持 OpenGL 4.3 的显卡和驱动
- 发布包不包含大型示例数据
