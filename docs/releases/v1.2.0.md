# v1.2.0

LAS Point Cloud Viewer `v1.2.0` 是一个面向 Windows x64 的桌面点云查看与电力巡检辅助版本，在 `v1.1.0` 基础上重点补强了主窗口工程化结构、Ribbon 与交互稳定性、点云裁切导出，以及内嵌屏幕录制工作流。

## 主要更新

- 新增内嵌屏幕录制能力，支持在主程序内直接开始/停止录制并导出 MP4(H.264)
- 新增点云裁切编辑与导出能力，支持围绕当前视图工作流整理局部数据
- 重构 `MainWindow` 编译单元边界，并同步整理 CMake 源码组织与构建脚本结构，降低后续 GUI 迭代成本
- 优化航线预览、标注与量测后的显示恢复逻辑，补充多项主窗口与航线回归验证
- 修复标题区拖拽/双击、主窗口闪屏、右侧 dock 窄屏收缩等桌面交互问题
- 调整 Ribbon 页面结构、布局与浅色主题可读性，修复页签文字显示和选中态样式问题

## 主要能力

- 加载一个或多个 `.las/.laz` 点云
- 多数据集项目树管理
- RGB、高程、单色、分类等点云显示模式
- 点大小、透明度、深度雾化、EDL 风格增强、圆形 splat
- 鼠标悬停坐标显示与多点连续量测
- 净空分析、剖面视图与 CSV 导出
- 杆塔编辑、隐患标注与巡检辅助工作流
- 航线导入、显示、编辑、预览、导出与漫游状态验证
- 点云裁切区域编辑与局部导出
- 内嵌屏幕录制与 MP4(H.264) 导出

## 运行环境

- Windows x64

## 使用方式

1. 下载 `LASPointCloudViewer-v1.2.0-windows-x64.zip`
2. 解压到任意本地目录
3. 运行 `LASPointCloudViewer.exe`
4. 在软件中导入 `.las/.laz` 数据开始使用

## 说明

- 本次 Release 提供的是最小可运行包，不包含大型示例点云
- 默认功能所需的 OSG、Qtitan、LASlib、LAStools、GDAL/PROJ 依赖已随包提供
- 录屏功能依赖 Windows 图形捕获链路，建议在支持的 Windows 桌面环境下使用
- 如需体验，可自行准备 `.las/.laz` 数据并在程序中打开
