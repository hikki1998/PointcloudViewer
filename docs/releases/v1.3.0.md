# v1.3.0

LAS Point Cloud Viewer `v1.3.0` 是首个提供 Windows / Linux 分平台发布包的版本。本版本在 `v1.2.0` 的点云浏览、量测、净空分析、杆塔/隐患、航线编辑和录屏能力基础上，重点补齐 Linux 构建、运行和打包路径。

## 下载包

- `LASPointCloudViewer-v1.3.0-windows-x64.zip`
  - 面向 Windows x64 桌面环境
  - 包含 Qt、OpenSceneGraph、QtitanRibbon、LASlib/LASzip、PROJ 等 Windows 运行依赖
  - 支持内嵌屏幕录制

- `LASPointCloudViewer-v1.3.0-linux-x64.tar.gz`
  - 面向 Ubuntu 22.04 / WSL2 Ubuntu 22.04
  - 包含主程序、仓库内 QtitanRibbon 兼容层动态库、翻译文件、启动脚本和 Linux 使用说明
  - Qt、OpenSceneGraph、PROJ/GDAL、LASzip 等基础库通过系统包安装

## 主要更新

- 新增 Linux 构建支持，验证环境为 Ubuntu 22.04 / WSL2 Ubuntu 22.04
- 新增仓库内 QtitanRibbon 兼容层，Linux 下可自动构建 `libqtnribbon4.so`
- 新增 Linux LAS/LAZ 读取路径，使用系统 LASzip C API
- 新增 Linux 编译文档与脚本：
  - `docs/linux-build.md`
  - `scripts/linux/setup-ubuntu-22.04.sh`
  - `scripts/linux/build-qtitan-shim.sh`
- CMake 支持 Linux 系统 Qt 5、OpenSceneGraph、PROJ、LASzip 包
- 修复 Linux / WSLg 下启动资源过大导致 X11 连接中断的问题
- 保留 Windows 现有 QtitanRibbon、LASlib/LASzip 和屏幕录制路径

## Windows 使用方式

1. 下载 `LASPointCloudViewer-v1.3.0-windows-x64.zip`
2. 解压到任意本地目录
3. 运行 `LASPointCloudViewer.exe`
4. 在软件中导入 `.las/.laz` 数据开始使用

## Linux 使用方式

先安装运行依赖：

```bash
sudo apt-get update
sudo apt-get install -y \
  libqt5opengl5 libqt5waylandclient5 libqt5waylandcompositor5 qtwayland5 \
  libopenscenegraph161 libproj22 libgdal30 liblaszip8 \
  libgl1 libglu1-mesa libxkbcommon-x11-0 libxcb-cursor0 libxcb-xinerama0
```

然后解压并运行：

```bash
tar -xzf LASPointCloudViewer-v1.3.0-linux-x64.tar.gz
cd LASPointCloudViewer-v1.3.0-linux-x64
./run-lasviewer.sh
```

如果在 WSLg 下窗口显示异常，可以尝试：

```bash
QT_QPA_PLATFORM=wayland ./run-lasviewer.sh
```

## 说明

- Linux 包当前依赖 Ubuntu 22.04 系统库，不是全静态便携包
- Linux 版本支持 LAS/LAZ 读取和点云浏览；LAS/LAZ 写回能力仍以 Windows LASlib 路径为主
- Windows 录屏功能依赖 Windows.Graphics.Capture，Linux 包不包含该录屏后端
- 本次 Release 不包含大型示例点云，请自行准备 `.las/.laz` 数据
