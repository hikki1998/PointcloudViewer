# v1.5.0

LAS Point Cloud Viewer `v1.5.0` 新增最近工程与最近数据工作台，重点优化大型 LAS/LAZ 的后台加载、预览和交互渲染，并修复 Gaussian 模型近距离显示和旋转交互问题。

## 下载包

- `LASPointCloudViewer-v1.5.0-windows-x64.zip`
  - 面向 Windows x64 桌面环境
  - 包含 Qt、OpenSceneGraph、QtitanRibbon、LASlib/LASzip、PROJ 等运行依赖

## 主要更新

### 最近工作台

- 空场景新增最近工程与最近数据入口
- 显示工程摘要、数据类型、文件大小和缺失状态
- 支持打开、追加到当前场景、定位文件夹和移除最近记录
- 支持场景缩略图缓存，启动时不会重新读取大型点云

### LAS/LAZ 加载与交互

- 单文件、多文件和追加导入均支持后台读取与 CPU 几何准备
- 大文件先显示渐进预览，完整数据就绪后自动切换
- 支持加载进度和取消，失败或取消时保留原场景
- 多数据集使用独立渲染节点，不再常驻完整合并副本
- 新增轻量 XY 拾取索引，降低大数据点选和悬停开销
- 相机交互期间使用有上限的抽样节点，修复释放鼠标后的显示闪烁

### Gaussian 渲染

- 修复窗口尺寸变化后的 Gaussian 渲染视口问题
- 修复近距离观察模型时可能出现的白屏
- 优化模型旋转、视图适配和 LAS/Gaussian 场景切换

### 维护与回归

- 将 MainWindow、PointCloudViewer 和 smoke 场景按职责拆分
- 统一为单个 `LASViewerSmokeTest`，覆盖 20 个主要场景
- 清理未使用资源、遗留示例和重复测试目录

## 使用方式

1. 下载 `LASPointCloudViewer-v1.5.0-windows-x64.zip`
2. 解压到任意本地目录
3. 运行 `LASPointCloudViewer.exe`
4. 从软件的数据入口加载 `.las`、`.laz` 或受支持的 Gaussian `.ply` 文件

## 说明

- Gaussian PLY 仍要求 binary little-endian、float32 3DGS 属性
- 当前渲染 SH0 颜色，不支持 SH1-SH3
- Gaussian 模型与 LAS/LAZ 当前不支持同屏显示
- Gaussian GPU 渲染需要支持 OpenGL 4.3 的显卡和驱动
- 发布包不包含大型示例数据
