# v1.0.0

LAS Point Cloud Viewer `v1.0.0` 是一个面向 Windows x64 的桌面点云查看与巡检辅助版本，基于 Qt 5.15、OpenSceneGraph 和 LASlib 构建，支持 `.las/.laz` 数据加载、基础浏览、量测分析和电力巡检业务标注。

## 主要能力

- 加载一个或多个 `.las/.laz` 点云
- 多数据集项目树管理
- RGB、高程、单色等点云显示模式
- 点大小、透明度、深度雾化、EDL 风格增强、圆形 splat
- 鼠标悬停坐标显示与多点连续量测
- 净空分析、剖面视图与 CSV 导出
- 杆塔编辑、隐患标注与巡检辅助工作流

## 运行环境

- Windows x64

## 使用方式

1. 下载 `LASPointCloudViewer-v1.0.0-windows-x64.zip`
2. 解压到任意本地目录
3. 运行 `LASPointCloudViewer.exe`
4. 在软件中自行导入 `.las/.laz` 数据开始使用

## 说明

- 本次 Release 提供的是最小可运行包，不包含大型示例点云
- 如需体验，可自行准备 `.las/.laz` 数据并在程序中打开
