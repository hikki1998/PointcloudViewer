# v1.1.0

LAS Point Cloud Viewer `v1.1.0` 是一个面向 Windows x64 的桌面点云查看与电力巡检辅助版本，在 `v1.0.0` 基础上重点补强了坐标系能力、航线编辑体验、杆塔与航线互操作，以及仓库内最小依赖闭环。

## 主要更新

- 新增并完善工程级 CRS 能力，支持坐标系选择、识别、转换与运行时 PROJ 数据部署
- 航线模块升级为可导入、显示、编辑、预览、导出的一体化工作流
- 新增航点与部件点联动表格、场景内航点拖拽、视锥体显示和右下角相机预览
- 补充航线互操作与多项 smoke test，覆盖 route JSON、interop、漫游状态、杆塔文件与工程关联
- 主页 Ribbon 按业务拆分，新增独立的 Route / Analysis / Issue 页面
- 优化点云精度链路与发布依赖整理，仓库内 `3rd/` 已包含默认功能所需最小三方库

## 主要能力

- 加载一个或多个 `.las/.laz` 点云
- 多数据集项目树管理
- RGB、高程、单色、分类等点云显示模式
- 点大小、透明度、深度雾化、EDL 风格增强、圆形 splat
- 鼠标悬停坐标显示与多点连续量测
- 净空分析、剖面视图与 CSV 导出
- 杆塔编辑、隐患标注与巡检辅助工作流
- 航线导入、显示、编辑、预览、导出与漫游状态验证

## 运行环境

- Windows x64

## 使用方式

1. 下载 `LASPointCloudViewer-v1.1.0-windows-x64.zip`
2. 解压到任意本地目录
3. 运行 `LASPointCloudViewer.exe`
4. 在软件中导入 `.las/.laz` 数据开始使用

## 说明

- 本次 Release 提供的是最小可运行包，不包含大型示例点云
- 默认功能所需的 OSG、Qtitan、LASlib、LAStools、GDAL/PROJ 依赖已随包提供
- 如需体验，可自行准备 `.las/.laz` 数据并在程序中打开
